# EnduroTelemetry

Este proyecto consiste en el diseño y desarrollo de un sistema de telemetría y mantenimiento inteligente personalizado para motocicletas de Hard Enduro. 

La idea principal es combinar el desarrollo de software con hardware integrado en la motocicleta para registrar datos precisos de las salidas (como rutas y movimientos) y utilizarlos para analizar el rendimiento en zonas técnicas y gestionar el mantenimiento preventivo del motor.

## Objetivos del Proyecto

* Crear un dispositivo físico autónomo que se instale en la motocicleta para recoger métricas de conducción.
* Desarrollar una aplicación (móvil y ordenador) que se conecte de forma inalámbrica con el dispositivo.
* Centralizar el control de las rutas y llevar un registro inteligente de las horas de uso y mantenimiento de la moto.
